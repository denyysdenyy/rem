# 3D-модель квартиры

Основная комната: 4,90 × 6,19 м. Принятая высота: 2,80 м. Мебель и часть проёмов восстановлены приблизительно по фото.

- `kvartira-3d.html` — интерактивный просмотр в браузере. Скачайте файл и откройте его в браузере с WebGL.
- `kvartira.glb` — модель для 3D-программ.
- `kvartira.blend` — редактируемая сцена Blender 4.3.
- `preview.png` — общий вид модели.

Модель, текстуры и шрифты встроены в HTML. Исходные фотографии в этот пакет не включены; кнопки просмотра фото скрыты.
