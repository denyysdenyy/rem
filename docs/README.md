# Публичный просмотр 3D-модели

Готовая статическая страница без исходных фотографий: `index.html`. Все ресурсы модели и шрифты встроены; внешние API и сборка не требуются.

## Активация GitHub Pages

В настройках репозитория откройте Pages → Build and deployment. Выберите Source: Deploy from a branch, Branch: main, Folder: /docs, затем Save.

После успешной публикации ожидаемый адрес: https://denyysdenyy.github.io/rem/ . Само наличие файлов в docs не означает, что Pages уже включён.
